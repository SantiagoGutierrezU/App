Plan de desarrollo para app de matemáticas para niños, estilo Duolingo

Haz clic en cualquier fase para explorarla con Claude ↗

Fases de desarrollo
Fase 1 Fundamentos y diseño ~2 semanas
Sistema de diseño: colores, tipografía, personaje mascota
Mapa de niveles (mundo de aprendizaje)
Perfil del niño y sistema de avatares
Sistema de recompensas y estrellas
Fase 2 Motor de ejercicios y animaciones ~3 semanas
Animaciones visuales: manzanas, animales, objetos para contar
Tipos: suma, resta, comparación, series numéricas
Retroalimentación animada (correcto/incorrecto)
Interacción táctil: arrastrar, tocar, contar
Fase 3 Progresión y gamificación ~2 semanas
Racha diaria (streak) y recordatorios
Insignias y logros desbloqueables
Progreso visual por unidad
Desbloqueo de niveles y contenido
Fase 4 Panel de padres y pulido ~2 semanas
Reporte de progreso para padres
Control de tiempo de pantalla
Efectos de sonido y música adaptativa
Optimización para tablet y móvil
Contenido curricular (por grado)
1° — Contar y sumas básicas 2° — Suma y resta hasta 100 3° — Multiplicación básica 4° — División y fracciones 5° — Operaciones mixtas 6° — Geometría y problemas
Stack tecnológico recomendado
Frontend / App
React Native Framer Motion / Lottie Tailwind CSS
Backend / Datos
Supabase (auth + DB) Node.js / Express PostgreSQL
Animaciones y sonido
Lottie Files Howler.js SVG animado
